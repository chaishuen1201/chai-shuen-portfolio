Screenshots and highlights for the Tetris project. Click images to open full-size files in the repository.

Technical Highlights

  • Game loop: Deterministic main loop with fixed timestep for consistent physics and input across devices.
  • Piece rotation: Super Rotation System (SRS) with wall-kick implementation for predictable rotation behavior.
  • Collision & line clear: Efficient grid-based collision detection and optimized line-clear batching to avoid frame hitches.
  • Scoring & progression: Level-based speed increase, combo tracking, and configurable scoring rules for single and multiplayer modes.
  • Input handling: Debounced keyboard/touch controls with repeat-rate handling and configurable control mapping.
  • Multiplayer sync: Peer matchmaking with authoritative server messages for garbage lines and match state reconciliation.
