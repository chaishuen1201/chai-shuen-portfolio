PROJECT OVERVIEW:
================================================================================
The ABB Robotics CRM (Customer Relationship Management) System is a comprehensive
web-based application designed to manage customer relationships, sales operations,
leads tracking, and business interactions. Built with PHP and MySQL, this system
enables organizations to efficiently track, manage, and optimize their customer
interactions and sales processes.

Database: COMP1044_Database
Technology Stack: PHP, MySQL, HTML5, CSS3, JavaScript
Server: Local MySQL Server (localhost:3306)

KEY FEATURES:
================================================================================
1. USER AUTHENTICATION & ROLE-BASED ACCESS
   - Secure login and signup functionality with password hashing
   - Two user roles: Admin and Sales Representatives
   - Session-based authentication
   - User profile management and editing capabilities
   - Password recovery options

2. CUSTOMER MANAGEMENT
   - Add, view, edit, and delete customers
   - Store customer information (name, contact details, etc.)
   - Sales history tracking per customer
   - Customer data retrieval and search functionality
   - Interaction history tracking with customers

3. LEADS MANAGEMENT
   - Add, view, edit, and delete sales leads
   - Lead tracking and conversion workflow
   - Follow-up management for leads
   - Interaction history for each lead
   - Search and filter lead functionality

4. SALES MANAGEMENT
   - Record and track sales transactions
   - Add new sales records with customer information
   - Edit and delete sales entries
   - Sales history per customer
   - Sale processing workflow

5. FOLLOW-UP MANAGEMENT
   - Create and manage follow-up reminders/tasks
   - Set follow-up dates and status tracking
   - Edit and delete follow-ups
   - Real-time notifications for upcoming follow-ups
   - Follow-up retrieval for specific customers or leads

6. INTERACTION HISTORY TRACKING
   - Record all customer and lead interactions
   - Edit interaction records
   - Delete interaction entries
   - Search interactions by customer or lead
   - Admin view of all interactions
   - Individual user interaction history

7. DASHBOARD & REPORTING
   - Admin dashboard with system overview
   - Sales dashboard for sales representatives
   - Graphical reports and analytics
   - Performance metrics visualization
   - Sales graphs and trends

8. SALES REPRESENTATIVE MANAGEMENT (Admin)
   - Manage sales representatives
   - Search and filter sales representatives
   - Add/Edit/Delete representative profiles

DATABASE STRUCTURE OVERVIEW:
================================================================================
The application uses MySQL database "COMP1044_Database" with tables:

Key Tables:
- Users: Stores user accounts, roles, authentication
- Customers: Customer information and details
- Leads: Lead prospects and pipeline
- Sales: Sale transactions and records
- FollowUp: Follow-up reminders and tasks
- InteractionHistory: All customer/lead interactions
- And supporting tables for relationships

================================================================================
USER ROLES & PERMISSIONS:
================================================================================

ADMIN ROLE (User ID prefix: ad)
- Full system access
- User management
- Sales rep management
- View all customers, leads, sales
- Access admin reports and graphs
- System configuration
- Interaction history access (all)

SALES REPRESENTATIVE ROLE (User ID prefix: sl)
- Manage assigned customers
- Manage assigned leads
- Record sales transactions
- Create and manage follow-ups
- Log interactions
- View personal performance reports
- Edit own profile

SECURITY FEATURES:
================================================================================
- Password hashing using PHP's PASSWORD_DEFAULT algorithm
- Session-based authentication
- Role-based access control
- SQL injection prevention via mysqli_real_escape_string
- Input validation and sanitization
- Secure form processing
- Session timeout management
