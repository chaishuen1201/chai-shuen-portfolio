Technical Highlights

  • Cross-platform: Built with Flutter to support mobile (iOS/Android) and web from a single codebase.
  • Real-time sync: Firestore integration enables live data synchronization across devices and sessions without manual refresh.
  • Image processing: Four-angle photo capture with quality validation ensures consistent model input for analysis.
  • Authentication flow: Email verification gates → Profile completion → Home dashboard ensures onboarding compliance.
  • Responsive design: Adaptive layouts handle small phones to large tablets; camera vs. gallery fallback on web.
  • State management: Provider/GetX patterns for efficient state updates across feature modules.
