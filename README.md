# Portfolio Website (starter)

This folder contains a simple starter portfolio scaffold for `chaishuen1201`.

Recommended repo name for GitHub Pages (root site): `chaishuen1201.github.io`

Alternative repo names:

- `chaishuen-portfolio`
- `chaishuen.dev` (if you want a shorter repo and use a custom domain)

To initialize the repository locally and push to GitHub (replace placeholders):

```bash
git init
git add .
git commit -m "Initial portfolio scaffold"
git branch -M main
git remote add origin https://github.com/chaishuen1201/chaishuen1201.github.io.git
git push -u origin main
```

After pushing, GitHub Pages will publish the site at `https://chaishuen1201.github.io/](https://chaishuen1201.github.io/chai-shuen-portfolio/`.
